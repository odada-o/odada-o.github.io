## ✨ About 오드오드

오드오드(oddodd)는 IT 기술 기반의 디지털 서비스 전문 개발팀입니다.  
스타트업과 기업을 위한 **API 포털**, **기업 홈페이지**, **관리자 어드민**, **디자인 시스템 구축** 등  
기획부터 UX/UI 디자인, 프론트엔드 개발까지 원스톱으로 제공합니다.

> 우리는 복잡한 백엔드 없이도 **깔끔하고 강력한 웹서비스를 구현**합니다.


## 🔧 기술 스택

- **Frontend**: React, Vue 3, Next, Nuxt, PrimeVue, TailwindCSS
- **Project Tools**: Figma, GitHub, Notion, Slack, Jira
- **Etc**: 웹 접근성(WAI-ARIA), 반응형 UI, SEO 최적화
